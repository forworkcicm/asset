# Pivot ตรวจนับครุภัณฑ์ CICM

ไฟล์เดียว `index.html` อ่านผลตรวจนับสดจากชีต `asset_count_list` (แท็บ ชีต1) แล้วสรุปตามอาคาร > ชั้น > ห้อง
ข้อมูลครุภัณฑ์หลัก (5,705 รายการ ณ 12 ต.ค. 2569) ฝังอยู่ในไฟล์แล้ว

## ตั้งค่า (ครั้งเดียว)
1. เปิดชีต > ส่วนขยาย > Apps Script วางโค้ดจาก `Code.gs`
2. ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > ประเภท "เว็บแอป"
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
3. คัดลอก URL ที่ลงท้าย `/exec` ไปวางในไฟล์ `index.html` ตรง `CFG.appsScriptUrl`
4. อัปโหลด `index.html` ขึ้น GitHub Pages (repo `forworkcicm/asset`) แล้วเปิดผ่าน URL ของ GitHub Pages ไม่ใช่หน้า blob

ถ้าแก้ `Code.gs` ภายหลัง ต้องเลือก "จัดการการทำให้ใช้งานได้" > แก้ไข > เวอร์ชันใหม่ จึงจะมีผล

## ทางเลือกที่ไม่ต้องใช้ Apps Script
แชร์ชีตเป็น "ทุกคนที่มีลิงก์ · ผู้อ่าน" หน้าจะอ่านผ่าน gviz ได้ทันทีโดยไม่ต้องตั้งค่าอะไร
แต่ทั้งชีตจะเปิดสาธารณะ รวมถึงคอลัมน์ user_count (เลขบัตรประชาชนผู้ตรวจนับ) จึงไม่แนะนำ

## หมายเหตุ
- รีเฟรชเองทุก 60 วินาที (ปรับที่ `CFG.refreshSec`) และเมื่อกลับมาเปิดแท็บ
- ถ้าเชื่อมต่อชีตไม่ได้ หน้าจะแสดงข้อมูลที่ฝังไว้ (12 ต.ค. 2569) และมีช่องใช้ไฟล์ CSV แทนชั่วคราว
- ถ้ามีครุภัณฑ์ใหม่ที่เพิ่มหลัง 12 ต.ค. 2569 หน้าจะแจ้งจำนวน asset_id ที่ไม่รู้จัก ต้องอัปเดตข้อมูลหลักในไฟล์นี้ใหม่
- repo ที่เป็น public จะเปิดข้อมูลครุภัณฑ์ที่ฝังอยู่ทั้งหมดต่อสาธารณะ (ชื่อ เลขครุภัณฑ์ ที่ตั้ง) ควรใช้ repo private หรือจำกัดผู้เข้าถึง
