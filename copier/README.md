# Dashboard ค่าเช่าเครื่องถ่ายเอกสาร

หน้าเว็บ HTML ล้วน ใช้ได้บน GitHub Pages โดยไม่ต้องมี PHP หรือเซิร์ฟเวอร์ใด ๆ

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `dashboard.html` | หน้า Dashboard ทั้งหมดอยู่ในไฟล์เดียว |
| `data.csv` | ไฟล์สำรอง ใช้เมื่อดึงจาก Google Sheet ไม่ได้ |

> ลบ `data.php` ออกจาก repo ได้เลย ไม่ได้ใช้แล้ว
> GitHub Pages เป็นโฮสต์แบบไฟล์นิ่ง รันไฟล์ PHP ไม่ได้ ที่ผ่านมาหน้าเว็บจึงได้ซอร์สโค้ด PHP กลับมาเป็นข้อความแล้วอ่านเป็นตารางไม่ได้

## เปิดหน้าเว็บอย่างไร

ต้องเปิดผ่าน **GitHub Pages** ไม่ใช่หน้า `blob` ของ GitHub

```
https://forworkcicm.github.io/asset/copier/dashboard.html
```

ถ้ายังไม่ได้เปิด Pages ให้ไปที่ repo -> Settings -> Pages -> Source เลือก `main` แล้วเลือกโฟลเดอร์ `/ (root)`

## ลำดับการดึงข้อมูล

หน้าเว็บจะไล่ลองทีละแหล่ง แหล่งไหนอ่านได้ก่อนก็ใช้แหล่งนั้น และบอกไว้ที่มุมบนของหน้าเสมอว่าใช้แหล่งไหนอยู่

1. **Google Sheet สด** ผ่าน gviz — ต้องตั้งชีตเป็น *ทุกคนที่มีลิงก์ · ผู้อ่าน*
2. **Google Sheet ที่เผยแพร่ไปยังเว็บ** — ใช้เมื่อวิธีแรกถูกเบราว์เซอร์บล็อก (CORS)
3. **`data.csv` ในโฟลเดอร์นี้** — ได้ผลแน่นอนเสมอ แต่เป็นข้อมูล ณ วันที่ commit

## การตั้งค่า

เปิด `dashboard.html` แล้วแก้บล็อก `CFG` ที่อยู่บนสุดของ `<script>`

```js
const CFG = {
  sheetId : '1epiIfBG3FE29f7RwsOZF8rozIpXWTMMqczl5Xvc57Y4',
  gid     : '2041319209',   // รหัสแท็บ บันทึกมิเตอร์
  pubCsv  : '',             // ใส่ลิงก์จาก เผยแพร่ไปยังเว็บ ถ้าต้องใช้วิธีที่ 2
  localCsv: 'data.csv'
};
```

### ถ้าขึ้นแถบแดงว่าโหลดไม่สำเร็จ

หน้าเว็บจะบอกว่าลองแหล่งไหนไปแล้วบ้างและติดตรงไหน ให้ไล่ตามนี้

1. เปิดชีต -> ปุ่ม **แชร์** -> การเข้าถึงทั่วไป -> **ทุกคนที่มีลิงก์ · ผู้อ่าน**
2. ถ้ายังไม่ได้ ให้ใช้วิธีเผยแพร่แทน
   ในชีตกด **ไฟล์ -> แชร์ -> เผยแพร่ไปยังเว็บ** เลือกแท็บ `บันทึกมิเตอร์` เลือกรูปแบบ **CSV**
   คัดลอกลิงก์ที่ได้มาวางที่ `pubCsv`
3. วิธีที่ได้ผลแน่นอน
   ในชีตกด **ไฟล์ -> ดาวน์โหลด -> CSV** เปลี่ยนชื่อไฟล์เป็น `data.csv` แล้ว commit ทับของเดิม

## อัปเดตไฟล์สำรอง

ทุกครั้งที่กรอกข้อมูลเดือนใหม่เสร็จ ถ้าอยากให้ `data.csv` ทันสมัย
ให้ดาวน์โหลดแท็บ `บันทึกมิเตอร์` เป็น CSV แล้ว commit ทับ
ถ้าดึงสดจาก Google ได้อยู่แล้ว ไม่ต้องทำขั้นนี้ก็ได้

## หมายเหตุเรื่องสูตร

```
จำนวนแผ่น    = มิเตอร์ครั้งหลัง − มิเตอร์ครั้งก่อน
กระดาษเสีย 3% = ปัดเศษ(จำนวนแผ่น × 3%)
ยอดใช้สุทธิ   = ปัดเศษ(จำนวนแผ่น × 97%)     <-- หักกระดาษเสียออก ไม่ใช่บวกเพิ่ม
ยอดเบิกคำนวณ  = ปัดเศษ(ยอดใช้สุทธิ × ราคาต่อแผ่น, 2)
ผลต่าง        = ยอดตามใบแจ้งหนี้ − ยอดเบิกคำนวณ
```
