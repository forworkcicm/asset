Dashboard ค่าเช่าเครื่องถ่ายเอกสาร — ชุดติดตั้งบน XAMPP
========================================================

ขั้นตอนที่ 1 : เปิดสิทธิ์อ่านชีต  (สำคัญที่สุด ถ้าข้ามขั้นนี้ Dashboard จะขึ้นแถบแดง)
  เปิด Google Sheet "ฐานข้อมูลค่าเช่าถ่ายเอกสาร"
  กดปุ่ม แชร์ มุมขวาบน -> หัวข้อ "การเข้าถึงทั่วไป"
  เปลี่ยนจาก "จำกัด" เป็น "ทุกคนที่มีลิงก์"  และตั้งบทบาทเป็น "ผู้อ่าน"
  แล้วกด เสร็จสิ้น

ขั้นตอนที่ 2 : เปิด php_curl ใน XAMPP
  XAMPP Control Panel -> ปุ่ม Config ของ Apache -> PHP (php.ini)
  หาบรรทัด   ;extension=curl    แล้วลบเครื่องหมาย ; ข้างหน้าออก
  บันทึกไฟล์ แล้วกด Stop และ Start ที่ Apache ใหม่

ขั้นตอนที่ 3 : คัดลอกไฟล์
  วาง dashboard.html และ data.php ไว้ที่   xampp\htdocs\main\
  เปิด   http://172.16.2.127/main/dashboard.html

ไฟล์ในชุดนี้
  dashboard.html   หน้า Dashboard
  data.php         ตัวดึงข้อมูลจาก Google Sheet พร้อมเก็บสำรองไว้ในเครื่อง
  cache_meters.csv จะถูกสร้างเองอัตโนมัติหลังดึงข้อมูลสำเร็จครั้งแรก

การตั้งค่าใน data.php
  SHEET_ID        รหัสไฟล์ Google Sheet  (ตั้งไว้ให้แล้ว)
  SHEET_NAME      ชื่อแท็บในไฟล์ ปัจจุบันคือ  บันทึกมิเตอร์
  CACHE_MINUTES   เก็บข้อมูลไว้กี่นาทีก่อนไปดึงใหม่ ปัจจุบัน 10 นาที
                  กดปุ่ม "โหลดข้อมูลใหม่" บนหน้าเว็บเพื่อดึงสดทันทีได้ตลอดเวลา

ข้อควรรู้
- ชีตต้องเปิดเป็น "ทุกคนที่มีลิงก์ อ่านได้" ใครที่ได้ลิงก์ไปก็เปิดดูได้
  ถ้าไม่ต้องการเปิดสาธารณะ ให้ดาวน์โหลดชีตเป็น CSV มาวางในโฟลเดอร์นี้
  ชื่อ cache_meters.csv แล้วตั้ง CACHE_MINUTES เป็นเลขสูง ๆ เช่น 99999
- Dashboard อ่านอย่างเดียว ไม่แก้ไขข้อมูลในชีต
- ถ้าเน็ตล่ม หน้าจะใช้ข้อมูลสำรองล่าสุดในเครื่อง และขึ้นจุดสีเหลืองบอกให้ทราบ
