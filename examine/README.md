# ประชุมตรวจสอบและตรวจนับพัสดุ ประจำปี 2569 (ครั้งที่ 1)

หนังสืออิเล็กทรอนิกส์ (อ่านออนไลน์แนวนอน 16:9) ของเอกสารประกอบการประชุม
งานยุทธศาสตร์และงบประมาณ (พัสดุ) วิทยาลัยแพทยศาสตร์นานาชาติจุฬาภรณ์ มหาวิทยาลัยธรรมศาสตร์
ประชุมวันที่ 14 กันยายน พ.ศ. 2569

## โครงสร้างไฟล์

| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | หน้าอ่านทั้งหมด (HTML ไฟล์เดียว ไม่ต้องติดตั้งอะไรเพิ่ม) |
| `pages/slide-01..11.jpg` | ภาพสไลด์ความละเอียด 1920×1080 |

## วิธีนำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `inventory-2569`) ตั้งเป็น **Public**
2. กด **Add file → Upload files** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `pages` และ `thumbs`) ลงไป แล้วกด Commit
3. ไปที่ **Settings → Pages** เลือก Source = `Deploy from a branch`, Branch = `main`, Folder = `/ (root)` แล้วกด Save
4. รอประมาณ 1 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/inventory-2569/`

หรือถ้าใช้ git บนเครื่อง

```bash
git init
git add .
git commit -m "ebook ตรวจนับพัสดุ 2569"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/inventory-2569.git
git push -u origin main
```

## การใช้งานหน้าเว็บ

หน้าอ่านใช้เอฟเฟกต์พลิกหน้ากระดาษ 3 มิติ (page flip / curl) ไม่ใช่การสไลด์

- **ลากมุมกระดาษ** ด้วยเมาส์หรือนิ้ว แล้วปล่อย — กระดาษจะพลิกตามมือ ถ้าลากไม่ถึงครึ่งจะดีดกลับ
- **คลิกครึ่งขวา** เพื่อพลิกไปหน้าถัดไป **ครึ่งซ้าย** เพื่อพลิกกลับ
- ลูกศร ← → / PageUp / PageDown / Spacebar — พลิกหน้า
- Home / End — ไปหน้าแรก / หน้าสุดท้าย
- B — สลับมุมมองหนังสือกางสองหน้า กับ อ่านทีละหน้า
- F — เต็มจอ, T — เปิดแถบภาพย่อ, Esc — ปิดเมนู
- จอกว้างจะเปิดเป็นหนังสือกางสองหน้าอัตโนมัติ จอแคบหรือมือถือจะเป็นทีละหน้า
- ลิงก์แต่ละหน้าใช้ `#p7` ต่อท้าย URL เพื่อส่งให้คนอื่นเปิดตรงหน้านั้นได้
- หน้าที่ 10 มีปุ่มเปิดโฟลเดอร์เอกสารแทนการสแกน QR

## การอัปเดตเนื้อหาภายหลัง

ถ้าแก้สไลด์แล้วส่งออก PDF ใหม่ ให้แปลงเป็นภาพด้วยคำสั่ง

```bash
pdftoppm -jpeg -jpegopt quality=88 -r 144 inventory-2569.pdf pages/slide
for f in pages/*.jpg; do convert "$f" -resize 400x -quality 78 "thumbs/$(basename $f)"; done
```

แล้วแก้ชื่อหัวข้อในตัวแปร `PAGES` ที่ท้ายไฟล์ `index.html`
