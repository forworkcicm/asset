# Sunrise — ระบบออกแบบหน้าเว็บของ cicm ชื่อเรียก: **Sunrise** (พูดว่า "ทำเป็นสไตล์ Sunrise" / "ใช้ธีม Sunrise" / "Sunrise style") ตัวอย่างอ้างอิง: หน้า e-GP (doc `code`) และหน้า 404 (doc `claude/404`) ในโปรเจกต์ egp --- ## 1. หลักการ - **ไฟล์เดียวจบ** — HTML + CSS + JS อยู่ในไฟล์เดียว ไม่ใช้ React/Vite/Tailwind/ไลบรารีภายนอก เปิดไฟล์แล้วใช้ได้ทันที วางบน Google Sites / เซิร์ฟเวอร์ไหนก็ได้ - **ไอคอนเป็น SVG ฝังในไฟล์** (ชุด Lucide) ไม่โหลดไลบรารีไอคอน - ฟอนต์เดียวที่โหลดจากภายนอกคือ Google Fonts - ภาษาไทยเป็นหลัก คอมเมนต์ในโค้ดเป็นภาษาไทยเพื่อให้แก้เองได้ ## 2. โทนสี — ประกาศเป็นตัวแปร CSS ชุดเดียวบนสุดของไฟล์เสมอ ```css :root { --hero-top: #FF8233; top: 0; z-index: 40` โปร่งใสตอนอยู่บน hero - เลื่อนพ้น hero → เติมคลาส `.scrolled` เป็นแถบไล่สี `--menu-top → --menu-bottom` + เงา - ซ้าย: โลโก้จุดขาว 2×2 (`grid-cols-2 gap 2px`, จุด 10–12px, กลม) + ชื่อระบบตัวหนา - กลาง/ขวา: ลิงก์ทรงแคปซูลพื้นขาว ตัวอักษร `--accent-deep` (ซ่อนบนจอเล็ก) - ขวาสุด: ปุ่มรอง (ghost, พื้นขาวจาง) + ปุ่ม "เมนู" พื้น `--accent` - ปุ่มบนจอเล็กเหลือเฉพาะไอคอน ข้อความซ่อนด้วย `.label { display: none }` ### 4.2 Hero เต็มจอ - `height: 100dvh; min-height: 560px; overflow: hidden` พื้นหลังไล่สี `--hero-top → --hero-bottom` - **ตัวอักษรยักษ์เป็นพื้นหลัง**: คำสั้น ๆ (ชื่อระบบ / เลข 404) สีขาว `font-weight: 900`, `line-height: 1`, `letter-spacing: -0.06em`, `white-space: nowrap`, `font-size: clamp(140px, 30vw, 520px)` วัด `offsetHeight` ตอนโหลด/resize/ฟอนต์พร้อม แล้วยืดแนวตั้งด้วย `transform: scale(1.15, (heroHeight * 0.92) / offsetHeight)` - **วงรีขาว** ทับกลางจอ `border-radius: 9999px`, สูง 60–72vh, กว้าง `clamp(150px, 23vw, 420px)` ทำหน้าที่บังช่องว่างกลางตัวอักษรและเป็นเฟรมให้ภาพประกอบ - ทั้งเลเยอร์: `opacity: 0.8` + `mask-image: linear-gradient(to bottom, black 45%, transparent 94%)` (ใส่ `-webkit-mask-image` ด้วย) และ `pointer-events: none` - ภาพประกอบ SVG กลางจอ ลอยขึ้นลงช้า ๆ (`floaty` 6s) ปิดเมื่อ `prefers-reduced-motion` - เนื้อหาล่าง: `margin-top: auto` — หัวเรื่องไทย + บรรทัดอังกฤษ + ชื่อหน่วยงาน + ปุ่ม CTA แคปซูล - หัวเรื่องไทยยาว ๆ ให้ใส่ `
